# Adventskalender-Quizze

Diese Liste dokumentiert den Text, der beim Öffnen eines Türchens vor dem Start des Quiz angezeigt wird. Die Fragen selbst sind nicht aufgeführt.

Bei einem Quiz mit normalem Fortschritt lautet der Button beim ersten Öffnen **„Quiz starten“**. Nach begonnenen Quizzen kann stattdessen ein Fortschrittshinweis mit **„Quiz fortsetzen“** erscheinen; bei abgeschlossenen Quizzen **„Zusammenfassung ansehen“**. Bei den Ranglisten wird außerdem der aktuelle Stand mit den verbleibenden Leben angezeigt.
